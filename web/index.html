Questions

The honest answers.

Is it really free?

Yes. There are no monthly caps. We apply fair-use daily limits to each account, and the service runs on free infrastructure, so extremely heavy use may hit platform limits.

What if you shut down?

Static QR codes keep working because they contain the address itself. You can export your data at any time, and the code is open source, so anyone can host a copy.

What do you store about visitors?

A scrambled fingerprint that changes every day, plus country, device, browser and the referring site. We never store IP addresses, and we use no tracking cookies.

How do I report a bad link?

Use the report page. A person reviews every report.
